# Archived and unmaintained

These projects are archived on GitHub or described by their authors as unmaintained. The main list is in [README.md](README.md).

- [ehsanhaghighat/sciann](https://github.com/ehsanhaghighat/sciann) - Keras wrapper for physics-informed deep learning. _(Python; license: MIT)_ **Note:** Author says it is unmaintained.
- [Kitware/iMSTK](https://github.com/Kitware/iMSTK) - Toolkit for interactive medical and surgical simulation. _(C++; license: Apache-2.0)_ **Note:** Discontinued in May 2025.
- [rcapillon/3DFEM](https://github.com/rcapillon/3DFEM) - 3D structural dynamics finite element code with uncertainty modeling. _(Python; license: GPL-3.0)_ **Note:** Author says it is unmaintained and not validated.
- [shayansss/hml](https://github.com/shayansss/hml) - Multi-fidelity hybrid machine learning surrogates for soft tissue biomechanics. _(Jupyter Notebook; license: MIT)_ **Note:** Requires Abaqus.
